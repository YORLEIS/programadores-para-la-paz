Al ejecutar el comando node server.js, Node.js inicia el servidor web y queda a la espera de solicitudes de los usuarios.

En la terminal aparece el mensaje: "Servidor ejecutándose en puerto 3000", indicando que el servidor está activo correctamente.

Cuando se visita la ruta /estado en el navegador, el servidor responde con información en formato JSON sobre el estado del servicio.

La respuesta obtenida es:

{
  "estado": "Servidor funcionando",
  "servicio": "API comunitaria"
}
